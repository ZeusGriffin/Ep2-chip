# Govee shortcut names

Create Apple Shortcuts with these exact names. The v8 NFC presets launch them through `shortcuts://run-shortcut`:

- Govee On
- Govee Off
- Govee Bright
- Govee Relax
- Govee Movie
- Govee Red
- Govee Blue

No Govee API key, password, or account token is embedded in the Wuzplay package. The iPhone/Shortcuts layer performs the Govee action.
