WUZPLAY CYBERDECK v8 - EXTERNAL STORAGE

CyberSync/WuzSync prepare text files for the Wuzplay Cyberdeck.
Use MTools BLE to copy the prepared files to the root of Wuzplay External Storage.

Common files:
- cyber.txt      Cyber Dashboard aggregate
- system.txt     iPhone system/device status
- network.txt    network/public-IP summary
- alerts.txt     user-provided alert text
- notes.txt      notes
- home.txt       home/reference information
- emergency.txt  emergency/reference information
