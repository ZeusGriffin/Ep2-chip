# Wuzplay Cyberdeck v8 capability map

This intentionally lists the custom v8 package behavior, not a stock/default pixl.js feature list.

## Verified in the gold DFU binary

The pre-verifier confirmed these custom strings inside the known-good `pixljs.bin`:

- Cyberdeck
- Cyber Dashboard
- Cyber Tools
- Back to Cyberdeck
- Cyber Shadow
- Arkanoid
- Invaders
- Lander
- Tris
- Card Emulator
- Amiibo Emulator
- Amiibo Database
- AmiiboLink
- BLE File Transfer
- Video Player
- Firmware Update

Target button order: **Left / Select / Right / Back**. Back is expected to return to the exact previous page.

## v8 companion NFC layer

19 presets are generated by `tools/make_nfc_pack.py`:

- CyberSync: System, Dashboard, Network, Tools, Alerts, All
- WuzSync: Open WuzSync
- iPhone workflows: Drive Home, Find Car, Flashlight, Quick Note, 10-Minute Timer
- Govee: On, Off, Bright, Relax, Movie, Red, Blue

These `.bin` files are companion NFC presets, **not DFU firmware**.

Architecture: `Wuzplay NFC emulation -> iPhone -> Scriptable/Apple Shortcuts -> requested action`.
