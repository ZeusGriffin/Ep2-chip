## What changed this session
1. **AI Face wired in** (BUILD_PLAN Phase 1, item 5). The already-tested
   `firmware/core/FaceMotion.*` state machine (see `FaceMotion_TESTED.md`) was
   previously written but never compiled into the build. Now:
   - `platformio.ini` gained `lib_extra_dirs = firmware` so PlatformIO treats
     `firmware/core/` as a library instead of duplicating those files into
     `src/`. (`CompanionInputs.cpp` compiles along with it but is never
     called — it needs an IMU this board doesn't have.)
   - New "FACE" page appended to `PAGE_NAMES` (index 5, after the 5 existing
     approved pages — their order/indices are untouched).
   - 3-tap SELECT on the FACE page enters a live animated face (two eyes,
     one mouth, vector-drawn, monochrome) instead of the generic framed-open
     box every other page uses.
   - 1-tap FORWARD, only while the face is live, cycles
     Idle → Listening → Thinking → Speaking for a hands-off demo (no AI
     backend exists yet to drive these states organically). FORWARD's
     behavior on every other page is unchanged (still a no-op while open).
2. **Header clock/date widget** (explicit ask). Small mono text, top-right of
   the persistent 30px header, fades to black then back in on an ~8s cycle:
   shows time (`%H:%M`) most of the time, briefly shows date (`%m/%d`) every
   cycle. Font is `FreeMono9pt7b` — **"NAPOSTMONO" doesn't match any bundled
   TFT_eSPI/GFXFF font and no font file was given**; using the existing mono
   as a placeholder. Hand over the real font (a `.ttf`) and it converts via
   TFT_eSPI's `fontconvert` tool.
   - Time source: one-shot **background, non-blocking** Wi-Fi STA connect +
     NTP sync at boot (`startClockSync()`/`pollClockSync()` in `main.cpp`),
     reading credentials from `include/secrets.h` (new, gitignored, currently
     **blank placeholders** — see Blocked below). The launcher is interactive
     immediately either way; sync just resolves quietly in the background.
   - Timezone hardcoded to US Central (`CST6CDT,M3.2.0,M11.1.0`, matches San
     Antonio, TX) with automatic DST handling twice a year.
   - **Never draws a fake/guessed time.** If Wi-Fi creds are blank, or the
     network is unreachable, or NTP times out, the widget simply stays
     hidden forever. No placeholder clock, no seeded fake time (the mistake
     already flagged as an open item on the NODE1/Cardputer project).
3. Compiled clean: `pio run -e nmtv154` → **SUCCESS**, 26s, RAM 18.6%,
   Flash 88.9% (1,165,225 / 1,310,720 bytes — watch this; each future
   Phase 1 app (Wi-Fi Radar, Miner, Games, Aquarium) will eat more of the
   remaining ~11%).
4. Committed and pushed to `origin/main`.
